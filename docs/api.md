# API 参考

以下接口仅用于文档展示，不提供真实服务。本页演示如何用 Markdown 描述一份接口文档的结构：
接口说明、参数表格、请求示例、返回示例、错误码。

## 查询文档列表

返回站点中所有文档条目的列表，用于构建目录页或搜索索引。

- 请求方法：`GET`
- 请求路径：`/api/docs`
- 功能：返回文档条目列表。

### 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `page` | query | integer | 否 | 页码，从 1 开始，默认 1 |
| `size` | query | integer | 否 | 每页条数，默认 20，最大 100 |
| `keyword` | query | string | 否 | 按标题模糊匹配 |

### 请求示例

```bash
curl -X GET "https://example.com/api/docs?page=1&size=20&keyword=指南"
```

### 返回示例

```json
{
  "items": [
    {"id": 1, "title": "使用指南"}
  ],
  "page": 1,
  "size": 20,
  "total": 4
}
```

## 查询单篇文档

- 请求方法：`GET`
- 请求路径：`/api/docs/{id}`
- 功能：按 ID 返回单篇文档的标题与正文。

### 路径参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `id` | integer | 文档唯一标识 |

### 返回示例

```json
{
  "id": 1,
  "title": "使用指南",
  "content": "本页说明一次完整的改文档到上线流程。",
  "updated_at": "2026-11-09T22:00:00+08:00"
}
```

## 错误码

| 状态码 | 含义 | 处理建议 |
| --- | --- | --- |
| `200` | 请求成功 | — |
| `400` | 参数格式错误 | 检查 `page`、`size` 是否为整数 |
| `404` | 文档不存在 | 确认 `id` 是否存在 |
| `429` | 请求过于频繁 | 降低频率后重试 |
| `500` | 服务内部错误 | 记录请求 ID 后联系维护者 |

## 字段约定

响应体统一使用 JSON，字段命名采用下划线风格，时间统一为带时区的 ISO 8601 格式：

```json
{
  "updated_at": "2026-11-09T22:00:00+08:00"
}
```
